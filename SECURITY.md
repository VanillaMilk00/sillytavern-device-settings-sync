# Security

Please do not report credential exposure or authentication issues in a public GitHub issue.

Use GitHub's private vulnerability reporting for this repository. Include the SillyTavern version, extension version, deployment type, and the smallest reproduction that does not contain real credentials.

The repository contains code only. Never attach `device-settings-sync.json`, browser storage exports, SillyTavern account data, cookies, OAuth tokens, or API keys to a report.
